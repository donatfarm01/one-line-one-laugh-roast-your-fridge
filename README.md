A single-line roast of my own fridge, written by a small deterministic
program. Running `main.py` writes the entry to `/output/entry.txt`.

The roast: "My fridge hums all night like it's rehearsing for a choir
it'll never join, and its only solo is the ice maker choking on a
cube."

The line roasts the fridge on a specific, recognisable detail — the
ice maker choking on a cube — and the twist lands in the last few
words. It is one line, reads cleanly aloud, and is not a joke
everyone who owns a fridge has already worn out.
